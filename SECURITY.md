# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in `mid`, please report it by emailing
ezeprimo.ia@gmail.com. Do **not** create a public GitHub issue for security
vulnerabilities.

You should receive a response within 48 hours. If you don't, please follow up.

Please include the following details in your report:

- A clear description of the issue
- Steps to reproduce the vulnerability
- The version of `mid` you are using
- Any relevant system information (OS, architecture)

## What to Expect

- I will acknowledge receipt of your report within 2 business days.
- I will provide an estimated timeline for a fix.
- I will notify you when the fix is released.
- I will credit you in the release notes (unless you prefer to remain anonymous).

Thank you for helping keep `mid` and its users safe.
